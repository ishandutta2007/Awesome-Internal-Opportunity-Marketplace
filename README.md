# Awesome-Internal-Opportunity-Marketplace

## Top Internal Opportunity Marketplace Tools Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Internal Talent Mobility, Skills-Based Matching & Career Development*  

**Last updated: March 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Internal Opportunity Marketplace Tools**. These tools help organizations match employees with internal gigs, projects, mentorships, and career paths — enabling talent mobility, skill development, and retention by surfacing opportunities that align with employee aspirations and business needs.



**Examples** include Salesforce Opportunity Marketplace, Gloat, Fuel50, Workday Talent Marketplace, Phenom Talent Marketplace, Eightfold AI, Hitch Works, Beamery, Degreed, and Cornerstone Galaxy (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom matching algorithms, and transparent employee data — ideal for HR engineering teams, people operations leaders, and developers building data-sovereign talent platforms.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects



- **[PeopleMesh](https://github.com/francescopace/peoplemesh)**  

  AI-powered matching layer for modern organizations, recognized in the Red Hat AI Quickstarts catalog. Helps people discover colleagues, internal opportunities, communities, and projects through semantic search that understands context. Models the organization as a graph-like mesh with embedding vectors for people, opportunities, groups, and initiatives. Privacy-first with granular consent controls, GDPR-aligned data rights, and pseudonymized audit trails. Apache 2.0 licensed core, with enterprise plugins for LDAP, Slack, LinkedIn, and Workday available separately .



- **[internal-talent-marketplace-engine](https://skills.rest/skill/internal-talent-marketplace-engine)**  

  Automates internal talent mobility with opportunity posting and candidate matching. Features skill-based candidate matching for internal roles, full lifecycle mobility management from posting to execution, analytics on mobility outcomes and retention rates, and manager veto workflows. Integrates with HR systems and corporate skill taxonomies .



- **[HRPulsar](https://dev.to/hr_pulsar/four-years-ago-we-started-building-an-hr-platform-29jo)**  

  Open-source talent management platform built around a competency-first model. Features competency graphs, grade systems tied to behavioral anchors, 360 assessments, internal talent marketplace, development plans, AI fluency tracking, and an AI workforce registry for tracking employee-AI tool assignments. Includes 200+ API endpoints, ~1000 automated tests, Docker-first deployment, and full self-hosting support. AGPLv3 licensed .



- **[SkillSync](https://github.com/harsh09jt/skillsync)**  

  AI-powered workforce skill intelligence and career development platform. Features employee profile management, skill tracking, gap analysis against target roles, personalized learning path recommendations, and AI-driven career guidance. Uses multi-agent AI architecture with Supervisor Agent coordinating specialized agents for workforce intelligence tasks. Spring Boot backend with MySQL, JWT authentication, and Gemini AI integration .



- **[JTP_PROJECT](https://github.com/harshspotted/JTP_PROJECT)**  

  AI-powered employee skill and project recommendation system. Features skills and expertise management with proficiency tracking, AI-powered project matching based on skill profiles, and personalized recommendations for roles and training programs. Uses Qdrant vector database for semantic search with optional Ollama LLM integration. Docker and Kubernetes deployment support .



- **[agentic-ai-career-intelligence](https://github.com/hasanbaroki/agentic-ai-career-intelligence)**  

  Agentic career intelligence system using LangGraph ReAct agent. Scores candidates against job descriptions, identifies skill gaps, and generates personalized learning plans with real-time resource research. API-first design supporting batch job description submission and background processing .



### Additional Strong Open-Source Options



- **[OpenHR](https://github.com/ArjunFrancis/OpenHR)** — Open-source HR and talent matching platform with skill-tag-based matching for founders and technical talent. React/Node.js MVP with smart matching algorithm and skills-based matching. MIT licensed .

- **[openhr-founder-ai](https://github.com/ArjunFrancis/openhr-founder-ai)** — Extended version with AI-powered semantic matching using Sentence Transformers, spaCy for NER, and LangChain/LangGraph for AI agents. PostgreSQL with Supabase, FastAPI ML pipelines .

- **[Algora](https://github.com/algora-io/algora)** — Open-source platform connecting companies and developers for full-time and contract work. Features bounty creation on GitHub issues, payment processing, and automated screening based on OSS contributions. Self-hostable or available via Algora.io .

- **[Giglance](https://github.com/upes-open/OSoC-25-Giglance)** — Open-source freelancing platform inspired by Upwork, built for beginners to gain real-world development experience. AI recommends matches with secure payment integration .

- **Embedding Models** — Sentence Transformers, OpenAI embeddings for semantic skill matching.

- **Vector Databases** — Qdrant, Weaviate, Milvus for skill and opportunity vector search.

- **Skill Taxonomy Tools** — ESCO, O*NET frameworks for standardized skill normalization.



**Frameworks for building custom systems**: Combine **PeopleMesh** for semantic talent discovery, **HRPulsar** for competency-based talent management, **SkillSync** for skill gap analysis, **JTP_PROJECT** for AI-powered project matching, and **Qdrant + PostgreSQL** for vector search and data persistence to build a complete self-hosted internal opportunity marketplace stack.
